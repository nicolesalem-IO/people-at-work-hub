# People At Work Hub

Use my established brand palette throughout this application:

#121016 near-black

#FACC15 yellow

#EC4899 pink

#FFFFFF white

Create a professional, approachable HR workspace with predominantly white content areas, near-black text and navigation, yellow primary actions, and restrained pink accents.

Prioritize readable forms, evidence tables, and document editors. Check accessible contrast for all text and interactive states. Do not rely on color alone to communicate status; include labels and icons.

Carry the brand through typography, spacing, buttons, and visual details while keeping the interface suited to the I-O workflow.
